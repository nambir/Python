🎯 Building Your First Voice AI

In this tutorial, we'll create a complete voice-to-voice AI application that can:

  • Listen to your voice input
  • Convert speech to text
  • Process the text with an AI model
  • Convert the response back to speech
  • Play the audio response
🎯 Goal: By the end of this tutorial, you'll have a working voice AI that can have conversations with you!

💻 Implementation

Complete Voice AI Application

import asyncio
import os
from dotenv import load_dotenv
from pipecat import Pipeline
from pipecat.transports import LocalTransport
from pipecat.processors.voice import OpenAISTTProcessor, OpenAITTSProcessor
from pipecat.processors.llm import OpenAILLMProcessor
from pipecat.processors.aggregators import LLMAssistantResponseAggregator

# Load environment variables
load_dotenv()

async def main():
    # Get API key from environment
    api_key = os.getenv("OPENAI_API_KEY")
    if not api_key:
        print("Please set your OPENAI_API_KEY in the .env file")
        return

    # Create processors
    stt = OpenAISTTProcessor(api_key=api_key)
    llm = OpenAILLMProcessor(api_key=api_key, model="gpt-4")
    tts = OpenAITTSProcessor(api_key=api_key)
    
    # Create transport for local audio
    transport = LocalTransport()
    
    # Create response aggregator
    aggregator = LLMAssistantResponseAggregator()
    
    # Build the pipeline
    pipeline = Pipeline([
        transport.input(),  # Audio input from microphone
        stt,                # Speech to text
        llm,                # AI processing
        aggregator,         # Response aggregation
        tts,                # Text to speech
        transport.output()  # Audio output to speakers
    ])
    
    print("🎤 Voice AI is ready! Start speaking...")
    print("Press Ctrl+C to stop")
    
    try:
        # Run the pipeline
        await pipeline.run()
    except KeyboardInterrupt:
        print("\n👋 Voice AI stopped. Goodbye!")

if __name__ == "__main__":
    asyncio.run(main())
📝 Code Explanation:
  • STT Processor: Converts your speech to text
  • LLM Processor: Processes the text and generates AI responses
  • TTS Processor: Converts AI responses back to speech
  • Transport: Handles audio input/output
  • Pipeline: Connects all components together

# Version with comprehensive error handling
import asyncio
import os
import logging
from dotenv import load_dotenv
from pipecat import Pipeline
from pipecat.transports import LocalTransport
from pipecat.processors.voice import OpenAISTTProcessor, OpenAITTSProcessor
from pipecat.processors.llm import OpenAILLMProcessor
from pipecat.processors.aggregators import LLMAssistantResponseAggregator

# Set up logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

load_dotenv()

async def main():
    try:
        api_key = os.getenv("OPENAI_API_KEY")
        if not api_key:
            logger.error("OPENAI_API_KEY not found in environment variables")
            return

        logger.info("Initializing Voice AI components...")
        
        # Create processors with error handling
        stt = OpenAISTTProcessor(api_key=api_key)
        llm = OpenAILLMProcessor(api_key=api_key, model="gpt-4")
        tts = OpenAITTSProcessor(api_key=api_key)
        transport = LocalTransport()
        aggregator = LLMAssistantResponseAggregator()
        
        # Build pipeline
        pipeline = Pipeline([
            transport.input(),
            stt,
            llm,
            aggregator,
            tts,
            transport.output()
        ])
        
        logger.info("Voice AI is ready! Start speaking...")
        print("🎤 Voice AI is ready! Start speaking...")
        print("Press Ctrl+C to stop")
        
        await pipeline.run()
        
    except Exception as e:
        logger.error(f"Error running Voice AI: {e}")
        print(f"❌ Error: {e}")
    except KeyboardInterrupt:
        logger.info("Voice AI stopped by user")
        print("\n👋 Voice AI stopped. Goodbye!")

if __name__ == "__main__":
    asyncio.run(main())

🔧 Troubleshooting

Common Issues and Solutions

⚠️ No Audio Input:
  • Check microphone permissions
  • Ensure microphone is not muted
  • Test microphone in other applications
⚠️ No Audio Output:
  • Check speaker/headphone connections
  • Ensure audio output is not muted
  • Test audio in other applications
⚠️ API Errors:
  • Verify your OpenAI API key is correct
  • Check your API usage limits
  • Ensure you have sufficient credits
💡 Performance Tips:
  • Use a good quality microphone for better speech recognition
  • Speak clearly and at a moderate pace
  • Minimize background noise
  • Use headphones to prevent audio feedback
