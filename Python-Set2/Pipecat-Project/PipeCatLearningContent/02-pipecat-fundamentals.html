🎯 What is PipecatAI?

PipecatAI is a powerful framework designed specifically for building real-time voice AI applications. It provides:

🎤 Real-time Processing

Ultra-low latency voice processing for natural conversations

🔧 Easy Integration

Simple Python API for rapid development

🌐 Multiple Providers

Support for various AI providers (OpenAI, Anthropic, etc.)

📱 Cross-platform

Works on desktop, web, and mobile platforms

💡 Key Advantage: PipecatAI handles the complex audio processing, streaming, and synchronization so you can focus on building your AI logic!

🧩 Key Components

1. Transport Layer

The transport layer handles communication between different parts of your application:

# Different Transport Options
from pipecat.transports import LocalTransport
from pipecat.transports import WebRTCTaskTransport
from pipecat.transports import TCPTransport

# Local transport for desktop applications
transport = LocalTransport()

# WebRTC transport for web applications
web_transport = WebRTCTaskTransport()

# TCP transport for network communication
tcp_transport = TCPTransport()

2. Audio Processors

Audio processors handle the conversion between audio and text:

# Speech-to-Text (STT) Processors
from pipecat.processors.voice import OpenAISTTProcessor
from pipecat.processors.voice import AzureSTTProcessor

# Text-to-Speech (TTS) Processors
from pipecat.processors.voice import OpenAITTSProcessor
from pipecat.processors.voice import AzureTTSProcessor

# Example STT processor
stt = OpenAISTTProcessor(api_key="your-api-key")

# Example TTS processor
tts = OpenAITTSProcessor(api_key="your-api-key")

3. LLM Processors

LLM processors handle the AI model interactions:

# LLM Processors for different providers
from pipecat.processors.llm import OpenAILLMProcessor
from pipecat.processors.llm import AnthropicLLMProcessor

# OpenAI LLM processor
llm = OpenAILLMProcessor(
    api_key="your-api-key",
    model="gpt-4"
)

# Anthropic LLM processor
claude_llm = AnthropicLLMProcessor(
    api_key="your-api-key",
    model="claude-3-sonnet"
)

4. Aggregators

Aggregators collect and manage responses from different components:

# Response Aggregators
from pipecat.processors.aggregators import LLMAssistantResponseAggregator
from pipecat.processors.aggregators import LLMUserResponseAggregator

# Assistant response aggregator
assistant_aggregator = LLMAssistantResponseAggregator()

# User response aggregator
user_aggregator = LLMUserResponseAggregator()

Basic Pipeline Example

from pipecat import Pipeline
from pipecat.transports import LocalTransport
from pipecat.processors.voice import OpenAISTTProcessor, OpenAITTSProcessor
from pipecat.processors.llm import OpenAILLMProcessor

# Create processors
stt = OpenAISTTProcessor(api_key="your-openai-key")
llm = OpenAILLMProcessor(api_key="your-openai-key", model="gpt-4")
tts = OpenAITTSProcessor(api_key="your-openai-key")

# Create transport
transport = LocalTransport()

# Build pipeline
pipeline = Pipeline([
    transport.input(),  # Audio input
    stt,                # Speech to text
    llm,                # AI processing
    tts,                # Text to speech
    transport.output()  # Audio output
])

# Run the pipeline
pipeline.run()
⚠️ Important: Remember to replace "your-openai-key" with your actual OpenAI API key!
